# App Theme (System, Light, Dark) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a native application-wide appearance theme feature (System, Light, Dark) toggled via a segmented picker at the top of the Settings Display tab.

**Architecture:** AppKit `NSApp.appearance` + SwiftUI `.preferredColorScheme` dual-layer drive. `AppTheme` is persisted in `UserDefaults` (`display.theme`) via `AppSettings.shared.theme`. `ThemeController` dynamically applies the appearance at launch and on mutation without requiring an app restart.

**Tech Stack:** Swift 6, SwiftUI, AppKit (`NSAppearance`, `NSApp`), XcodeGen, Localizable.xcstrings.

### Task 1: Create `AppTheme` and `ThemeController`

**Files:**

- Create: `Sources/Settings/ThemeController.swift`

- [ ] **Step 1: Create `AppTheme.swift`**

```swift
import SwiftUI

/// The available visual themes for the application.
enum AppTheme: String, CaseIterable, Identifiable, Sendable {
    case system = "system"
    case light = "light"
    case dark = "dark"

    var id: String { rawValue }

    var colorScheme: ColorScheme? {
        switch self {
        case .system: return nil
        case .light: return .light
        case .dark: return .dark
        }
    }

    var systemImage: String {
        switch self {
        case .system: return "circle.righthalf.filled"
        case .light: return "sun.max"
        case .dark: return "moon"
        }
    }

    var localizationKey: LocalizedStringKey {
        switch self {
        case .system: return "settings.display.theme.system"
        case .light: return "settings.display.theme.light"
        case .dark: return "settings.display.theme.dark"
        }
    }
}
```

- [ ] **Step 2: Create `ThemeController.swift`**

```swift
import AppKit

/// Controls application-wide appearance (Aqua vs. Dark Aqua vs. System default).
@MainActor
enum ThemeController {
    static func apply(theme: AppTheme) {
        switch theme {
        case .system:
            NSApp.appearance = nil
        case .light:
            NSApp.appearance = NSAppearance(named: .aqua)
        case .dark:
            NSApp.appearance = NSAppearance(named: .darkAqua)
        }
    }

    static func applyStoredTheme() {
        apply(theme: AppSettings.storedTheme)
    }
}
```

- [ ] **Step 1: Add `SettingsKey.theme` and property to `AppSettings.swift`**

In `SettingsKey`:
```swift

```

In `AppSettings`:
```swift
    nonisolated static var storedTheme: AppTheme {
        let raw = UserDefaults.standard.string(forKey: SettingsKey.theme) ?? ""
        return AppTheme(rawValue: raw) ?? .system
    }

    var theme: AppTheme {
        get { Self.storedTheme }
        set {
            set(newValue.rawValue, SettingsKey.theme)
            ThemeController.apply(theme: newValue)
        }
    }
```
