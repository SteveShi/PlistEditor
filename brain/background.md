# Project background

PlistEditor is a clean, modern property list (`.plist`) and XML editor for macOS. It offers a structured tree-based editing interface alongside raw XML source inspection with full type safety.

## Goals
- Provide a fast, crash-free property list editor for macOS developers.
- Support both XML and binary plist formats.
